# 开箱提示词

## 系列物料规划

```text
请使用 $create-xilehui-brand-poster 为本届喜乐会建立系列物料计划，包含 4:5 预热海报、9:16 报名长图、1:1 社交头像和 16:9 屏幕画面。先整理需求卡、规格矩阵、联合署名区和跨比例不变量，再给 3 个构图或媒介逻辑明显不同的视觉命题，等我选方向后再制作。
```

## 信息尚未齐全的审核稿

```text
制作一张 4:5 报名海报。活动全称和日期使用 current-campaign.md；地点、价格、截止时间和二维码尚未确认。继续完成可审核的视觉稿，但不能从旧稿推断信息，二维码区域明确标为“二维码待填”。
```

## 成稿审核

```text
审核 inputs/ 中的组员海报，按品牌硬约束、信息真实性、联合署名完整性、开放式审美和发布可靠性给出“可以发布 / 修改后发布 / 不可发布”的结论。把问题分成必须修改、建议优化和可保留三类；能运行的资产与配色审计要给出真实结果。
```

## 局部稳定改版

```text
保留已确认的构图、配色、建筑和主标题，只增强日期在手机缩略图中的可读性。不要顺手更换其他元素。输出修改前后对比、高清稿和新的审核记录。
```
