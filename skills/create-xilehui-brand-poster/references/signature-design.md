# 有序相聚

以横向延展与圆形聚合建立秩序。长标承担机构识别，圆章形成收束；通过可见图形中心和视觉重量组织关系。精细的等比缩放与留白，让两种轮廓自然共处，避免机械地把外框设成同样大小。

石灰米提供安静、连续的承托，勃艮第红构成主场。金色只连接文字与细部；机构标识保留原生色。对色彩和边缘的细致处理，应体现成熟的品牌排版工艺。

横向排列让视线平稳向右，纵向排列为窄幅载体保留更大的标识宽度。每次换行都回应媒介尺度；每段空白都承担分组作用，不用边框和分隔线填补空间。

学校身份、活动名称、活动标识和班级标识各自保有明确层级。经过精确校准的字号、间距与边缘，构成克制而完整的视觉系统。让有限元素经过充分打磨，形成稳定、可信的整体。
