# 喜乐会对外物料联合署名规范

## 适用范围

所有准备对外发布的喜乐会海报、长图、推文配图、报名头图、电子门票、屏幕画面和赞助物料，必须同时出现：

1. 厦门大学管理学院校友会完整标识；
2. 厦门大学管理学院“三证合一”完整横向标识；
3. 25MEM 班徽。

内部构图草稿可以暂时不放，但进入审核稿和发布稿前必须补齐。联合署名只出现一次，不重复铺陈，不替代主标题，也不替代画面中承担“厦大身份”的建筑、校徽或标准校名组合标志。

## 固定关系与颜色例外

- 默认顺序为“管理学院校友会标识在左、三证合一标识居中、25MEM班徽在右”，相邻身份之间保留细分隔线。不得交换顺序、拆出认证标识、删字、重排、描边或用生成模型重建。
- 只允许等比缩放、整体移动与选择浅底／深底版本。不得拉伸、透视、旋转、裁切标识主体、改变内部间距或添加投影、发光和金属特效。
- 三个标识的蓝、青、绿、红、黑和白均为机构标识原生色，是品牌六色之外的受控例外。例外只存在于锁定 PNG 内部，不得抽取为画面装饰色，也不计入喜乐会主视觉面积比例。
- 不制作自定义单色版。深色画面使用 S05 的石灰米承托底，避免直接把深蓝、红色和黑色细节压在酒红背景上。

## 布局层级

联合署名承担“发布主体与合作身份确认”，层级低于主标题、活动名称和主要行动信息，高于页脚英文装饰与版权小字。优先放在底部独立署名区；不得悬浮在主标题旁、压在人物面部、建筑屋脊、二维码静区或表格内容上。

推荐尺度：

- 竖版 3:4、4:5、3:5、9:16：署名区约占画布高度 4%–10%，联合署名宽度通常占画布宽度 44%–92%；信息型海报优先 70%–92%，门票等密集功能稿可在完整可辨识前提下降到 44%–60%。
- 横版 16:9：署名区约占画布高度 8%–13%，联合署名宽度约占画布宽度 44%–66%。
- 短横幅或报名头图：优先横跨底部或右下角，宽度约占画布 58%–82%；信息过密时先压缩次要装饰，不缩到不可辨识。
- 1080 px 宽的手机长图中，标准联合署名建议不低于 840 px 宽；375 px 宽的小图中不低于 318 px 宽。

联合署名外侧至少保留相当于 25MEM 班徽直径 0.22 倍的安全空间。与正文、表格边框或二维码之间至少保留画布短边的 2.5%；若使用 S05，其米色承托板视为完整图形，不叠加其他文字。

## 手机端与审美校验

在原尺寸、25% 缩略图和目标手机尺寸各检查一次：

1. 三个身份标识均可被识别：校友会凤凰花与“校友会”文字不糊成噪点，班徽保持可辨，三证合一标识的主要字形与三个认证图形不糊成色块；
2. 署名区与主内容有明确留白，不造成“底部又塞了一行信息”的拥挤感；
3. 署名只承担收束，不抢主标题、价格、日期或报名入口；
4. 深底版本的米色承托板边缘完整，无透明黑边、白边、锯齿和裁切；
5. 三个标识长宽比、颜色、顺序与内部关系和标准资产一致。

若画布过小导致上述条件不能同时成立，应重新分配版面或把对外物料改成更适合的比例，不得以省略任一标识作为解决方案。
