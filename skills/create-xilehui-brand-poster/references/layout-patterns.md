# 版式探索起点

以下模式用于打开构图，不是固定模板。先根据传播目的决定第一视觉，再选择厦大元素的角色；不要默认“建筑必须在左、标题必须在右”。

## 横版电子门票 / 屏幕海报（16:9）

可探索：

- 建筑或校名标识作为侧边身份锚点，文字建立另一组重心；
- 标题跨越全幅，建筑以局部裁切、底部地景或负形出现；
- 中轴、对角、三联画或非对称编辑网格；
- 摄影、算法图形或抽象色域作为主视觉，厦大元素以精确线稿融入。

功能区保持紧凑，二维码不得成为最大视觉模块。联合署名优先沿底边形成横向收束，通常占画布宽度 44%–66%，与行动区错位而不相互挤压。

## 竖版电子门票 / 报名长图（3:5、9:16）

可探索：

- 顶部纪念碑式主图、中段标题与底部信息；
- 纵向字体主导，建筑沿侧边形成连续结构；
- 大面积图像叙事，文字以编辑式栏目嵌入；
- 上下分镜、中心徽章或自由裁切的海报式构图。

让阅读路径自然向下，避免把所有重要内容挤在同一端。二维码区域仅占完成行动所需面积。底部预留 6%–10% 高度作为联合署名与安全空间，信息型长图不得等排完正文后再硬塞 Logo。

## 社交媒体海报（4:5、1:1）

优先强化单一传播目的。可以只保留一个厦大识别点和一组核心文案，通过大胆裁切、字体、图形系统或影像建立缩略图辨识度。详细信息移至配文或后续长图。联合署名仍须保留，但作为底部安静收束，不增加额外组织文字。

## 无二维码品牌公告

移除骰子和报名入口，不保留空白占位。使用日期、短主题语、厦大元素或一个强图形动作收束画面；不必用装饰框填满空间。若属于对外公告，联合署名仍为必选。

## 短横幅 / 报名表头图

画布高度有限时，先保持主标题与活动口径清楚，再把联合署名放在底部横带或右下角安静区域，宽度约占画布 58%–88%。不得把校友会标识或三证合一横标压缩成细线，也不得只保留25MEM班徽。若内容与署名无法同时辨识，应减少装饰或增加画布高度。

## 多版本比较

首轮输出 2-4 个真正不同的视觉命题，而不只是移动坐标：

1. 编辑式 / 字体主导；
2. 建筑或校园影像主导；
3. 生成艺术 / 抽象图形主导；
4. 当代东方 / 材质叙事主导。

所有版本保持相同品牌色、官方信息和厦大元素准确性，让用户比较创意方向。
