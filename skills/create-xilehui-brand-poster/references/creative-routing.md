# 辅助 skill 路由

只加载完成当前交付物所需的最小 skill 组合。喜乐会 skill 始终负责品牌口径、官方素材和最终验收；辅助 skill 负责媒介方法。

## 静态艺术海报：`canvas-design`

适用于单页 PNG/PDF、艺术海报、封面和展览感视觉。先按其要求建立视觉哲学，再制作画布并进行二次精修。品牌色与厦大官方元素覆盖其自由配色或素材建议；信息较多时，允许根据实际传播需求增加必要文字，不机械追求“90%视觉、10%文字”。

## 生图与参考图改稿：`imagegen`

适用于摄影感主图、插画、场景、非官方装饰物、抽象背景和材质探索。默认使用内置生图工具。不得让模型生成厦大建筑、校徽、组合标志、二维码或最终文字；这些必须在后期用 `assets/` 与真实字体叠加。将最终选中的项目素材复制到工作区。

## 生成艺术：`algorithmic-art`

适用于流场、粒子、拓扑、参数化几何和可复现的动态背景。使用固定随机种子，保留交互 HTML，并导出选定种子的静态层供海报合成。算法艺术提供主图或纹理，不替代活动文字与厦大标准元素。

## 可编辑 Figma：`figma-use` 与 `figma-generate-design`

用户明确要求 Figma 可编辑稿时，调用任何 Figma 写操作前必须先加载 `figma-use`。单张静态海报可直接用 `figma-use` 建立变量、字体和图层；只有交付物属于多区块活动页、落地页或复杂屏幕时，才同时加载 `figma-generate-design`，按其组件与设计系统流程逐区构建。每一步截图验收并返回节点 ID。

## 系列视觉系统：`theme-factory`

适用于同一活动的一组海报、PPT、长图和数字页面。参考其字体配对与主题组织方法，创建受 `brand-system.md` 约束的自定义主题；不要直接套用会改变喜乐会品牌色的预设主题。若直接调用该 skill，按其流程先展示主题方向并取得用户确认。

## 推荐组合

- 高级静态海报：`canvas-design`。
- 摄影或插画主图海报：`imagegen` → `canvas-design`。
- 生成艺术主视觉：`algorithmic-art` → `canvas-design`。
- 可编辑系列物料：自定义 `theme-factory` 主题 → `figma-use`。
- 可编辑活动页：`figma-use` + `figma-generate-design`。

当前环境没有可用的 `frontend-design` skill，不把它写成运行依赖；未来安装后可用于数字海报、交互视觉和 Web Art。
