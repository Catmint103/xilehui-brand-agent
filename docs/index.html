01

Install once, create repeatedly

两种方式，直接开工

推荐完整智能体工程

克隆后从仓库启动 Codex

获得 AGENTS.md、品牌 skill、素材、示例、报告和自动检查。适合组员共同生产物料。

git clone https://github.com/Catmint103/xilehui-brand-agent.git
cd xilehui-brand-agent
./install.sh
codex --cd .
Skill only已有自己的工作目录

只安装品牌 Skill

把 skill 安装进 ~/.codex/skills，下一个 Codex 任务即可显式调用。

curl -fsSL https://catmint103.github.io/
xilehui-brand-agent/install.sh | bash

提示 已安装旧版时运行 ./install.sh --force。旧目录会先备份，不会静默删除。安装后请重新开始一个 Codex 任务。

02

From brief to release

不是提示词，是生产工作流

01

需求卡

把输入拆成已锁定、可自主和待确认，阻止旧稿信息混入本届事实。

02

创意路由

根据物料选择静态画布、生图、算法艺术或 Figma 的最小组合。

03

差异探索

首轮提供 2–4 个真正不同的视觉命题，不把历史样例当固定模板。

04

真实编排

标准资产与真实文字进入母版，批量比例逐张重构而不是拉伸。

05

双重验收

资产哈希、配色审计负责机械预警；开放式审美与功能检查由人完成。

06

发版留痕

预览、高清、可编辑稿和审核记录成套交付，最终发布仍需组长批准。

Safety by design

会创作，也知道
哪些事不能猜

地点、票价、报名截止时间和正式二维码没有确认时，智能体会继续制作带明确占位的审核稿，但绝不从历史案例自动继承。

查看素材许可边界 →
  • 01
    不生成官方身份

    模型不重画校徽、厦大建筑、组合标志、二维码或最终文字。

  • 02
    不冒充业务确认

    没有证据时不声称已发布、已扫码成功或已获主办方确认。

  • 03
    不让审计替代审美

    配色与哈希是预警工具，构图张力、文化语境和完成度仍由人判断。

  • 04
    不公开内部数据

    inputs 与 outputs 默认不进 Git，防止名单、二维码和未发布物料泄露。
